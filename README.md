
# 🚀 Personal Portfolio Website - Fatima Zaheer

A modern, responsive, and high-performance developer portfolio built with **React.js** and **Vite**. Designed with a dark glassmorphism aesthetic to showcase full-stack MERN projects, technical skill sets, and contact information.

---

## ✨ Features

- **Modern Glassmorphism UI**: High-contrast dark theme designed with clean CSS styling.
- **Projects Showcase**: Interactive card grid highlighting full-stack MERN monorepos, API integrations, and web apps.
- **Dynamic Navigation**: Smooth section scrolling and external GitHub links.
- **Responsive Layout**: Fully optimized for mobile, tablet, and desktop screens.

---

## 🛠️ Tech Stack

- **Frontend**: React.js (Vite template)
- **Styling**: Modern CSS3 (Flexbox, CSS Grid, Custom Variables)
- **Icons**: Lucide React
- **Deployment**: Vercel
